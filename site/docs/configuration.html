Configuration

Everything lives under ~/.opcode/. You rarely touch any of it by hand — /login stores keys, /model persists the model, /theme the palette — but the files are plain JSON and documented here.

config.json

{
  "model": "anthropic/claude-sonnet-4.5",
  "mode": "build",
  "theme": "dark",
  "context_window": 200000,
  "compaction_model": "openrouter/cheap-sum",
  "update_checks": false
}
  • model — provider/model; written by picking a model in the UI.
  • mode — plan, build, or full-auto.
  • theme — dark (violet), light, teal, or green.
  • context_window — the model's context size in tokens. Enables compaction and the working line's occupancy readout; 0 (absent) means unknown and nothing is guessed.
  • compaction_model — the model that summarizes older context; unset means compaction is off.

auth.json

Provider keys, written by /login, stored 0600. A value starting with ! runs as a command (a secret manager's op read …) — only from this file, never from a project directory.

models.json

Custom endpoints and pinned model lists:

{
  "default_provider": "anthropic",
  "providers": {
    "my-proxy": {
      "base_url": "https://proxy.internal/v1",
      "api": "openai",
      "api_key_env": "MY_PROXY_KEY",
      "models": ["gpt-4o", "gpt-4o-mini"]
    }
  }
}

An explicit entry always wins over the built-in catalog, and custom providers join every picker.

Environment

OPCODE_HOMEMove the config directory (default ~/.opcode).
OPCODE_THEMEdark or light, when the terminal background is undetectable.
OPCODE_PLAINASCII-only posture: no unicode glyphs, no animations (also auto-detected for screen readers).
OPCODE_NO_UPDATE_CHECKDisable the startup update check.
<NAME>_API_KEYProvider keys, when not in auth.json.
